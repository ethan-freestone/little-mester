## Known installation defect

The owner reports that system installation generated
`lib/vm/__pycache__/code-update-transaction.cpython-314.pyc` inside the pinned
immutable `/opt/little-mester/v3/<SHA>` tree. The pinned-tree integrity check
then rejected the installation. The owner manually removed the generated bytecode;
startup succeeded afterward. That deletion is not a supported workaround. The
next integration PR must prevent generated bytecode at its source and add a
regression for install → system provisioning → pinned-tree verification → start.
